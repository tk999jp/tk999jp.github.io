Keybindings Reference

キー操作ガイド

MidFD はキーボードでの素早い操作を重視して設計されています。
「MidFD標準」と「FD／WinFD互換」の2つの操作方式をサポートしており、設定から好みの割り当てに変更できます。

最初に覚える基本キー

まずは以下の基本操作を覚えると、すぐに MidFD を使い始めることができます。F1～F12の割り当ては、後半のプロファイル別表を確認してください。

機能 共通キー 説明
開く / 実行 Enter ..は親フォルダー、フォルダーはMidFD内で移動、ファイルは対象に応じて開く／実行します。
内蔵ビューアー／プレビュー V 選択したファイルをMidFD内でプレビューします。
関連付けで開く Z フォルダーはExplorer、ファイルはOSの既定アプリで開きます。
外部エディタで開く E Browserで選択したファイルを外部エディタで開きます。内容検索結果のEは選択中の一致箇所を開きます。
コマンド実行 X コマンド・引数・Working Directoryを指定します。Working Directoryを空欄にすると現在のBrowser directoryを使います。
Command Palette Ctrl + Shift + P 機能、設定、外部ツールなどをすばやく検索・実行します。
移動履歴（Logdsk） L / F9 過去の移動履歴からディレクトリを素早く移動します。F9は両プロファイル共通です。
QuickAccess Q 登録済みの場所や最近使ったフォルダーへ移動します。

操作 キー 説明
上下移動 ↑ / ↓ 選択項目を上下に移動します。
左右移動（列） ← / → 複数列表示時、選択項目を左右の列へ移動します。
ページ移動 PageUp / PageDown 一覧をページ単位でスクロールします。
親ディレクトリへ移動 Backspace / Alt + ↑ 現在位置の1つ上のフォルダーへ移動します。
ディレクトリ履歴を戻る Alt + ← / Ctrl + Backspace 移動履歴を1つ戻ります。
ディレクトリ履歴を進む Alt + → 移動履歴を1つ進みます。
タブ履歴を戻る Alt + Shift + ← タブ訪問履歴を1つ戻ります。
タブ履歴を進む Alt + Shift + → タブ訪問履歴を1つ進みます。
ドライブのルートへ \（バックスラッシュ/円マーク） 現在のドライブの最上層（ルート）へ移動します。
パスの直接入力 Ctrl + L パス入力欄を開いて直接フォルダーパスを指定します。%TEMP% や %USERPROFILE% などの環境変数を含むパスも指定できます。

表示・整理

操作 キー 説明
Reload（再読込） Ctrl + R / Shift + R 現在フォルダーの内容を最新に更新します。
一覧Filter F 現在表示中の一覧だけを絞り込みます。filesystemを再帰検索しません。
配下Search Ctrl + F / F7 現在のBrowser tabをrootに配下を再帰検索します。名前／内容の使い分けと結果操作はFilter / Searchを参照してください。
頭文字jump @の後に1文字 Browser一覧のfocus中、入力した1文字で始まる項目へ移動します。
ソート順変更 プロファイル別Fキー表を参照 ソート順変更ダイアログを開きます。
ディレクトリツリー T 視覚的なディレクトリツリーを開きます。
表示モード切替 Ctrl + 1 / Ctrl + 2 / Ctrl + 3 / Ctrl + 4 / Ctrl + NumPad4 「ファイル名のみ」「ファイル名＋サイズ」「ファイル名＋サイズ＋更新日時」「拡張子整列」を切り替えます。拡張子整列は同じ表示列のfileで拡張子の開始位置を揃えます。
システム情報 I ドライブ使用量やメモリなどのシステム状況を表示します。
設定を開く O / Alt + F5 設定ダイアログを開きます。

画像・動画・音声の開き方

Browserで選択した項目の種類とキーに応じて開き先が変わります。ZはファイルをWindowsの関連付けで開きます。BrowserではEと（MidFD標準の割り当てでは）F4で外部エディタを開きます。FD／WinFD互換ではF4は削除です。

Browser操作動作
Enter（対応画像）選択した画像を内蔵ビューアーで表示します。通常は設定に応じてBrowserの選択変更に追従します。Susieプラグインを使う画像は、登録・有効化と検査が済み、対応形式として確認されたものが対象です。
Ctrl + Enter（単一画像）選択中の画像を内蔵ビューアで開き、固定表示にします。固定を解除すると、Browserの選択に追従します。
Enter（動画）内蔵MidPlayerで動画を再生します。再生中／一時停止中は自動的に固定され、停止または再生終了後はBrowserの選択に追従します。
Ctrl + Enter（動画）内蔵MidPlayerで動画を開きます。再生時の固定動作はEnterと同じです。
Enter / Ctrl + Enter（対応音声）設定済みの外部再生アプリで開きます。
ZファイルをWindowsの関連付けで開き、フォルダーはエクスプローラーで開きます。
E / MidFD標準のF4Browserで選択中のファイルを設定済みの外部エディタで開きます。未設定の場合はMidFDの既定の動作に従います。

Filter / Search

操作 キー／条件 説明
現在一覧Filter F 現在表示中の一覧だけを絞り込みます。ファイルシステムを再帰検索しません。
Search Ctrl + F / F7 現在のBrowserタブで開いているフォルダーと、その配下を再帰検索します。
名前検索 検索画面の内容欄を空にする ファイル名条件で、その配下のファイル／フォルダーを検索します。
内容検索 検索画面の内容欄へ入力する 配下のファイル内容を検索します。必要に応じてファイル名条件も使えます。

FilterとSearchは別の画面で、入力した検索条件は共有しません。ripgrep 15.2.0は配布ZIPに同梱されているため、通常は別途導入不要です。

内容検索結果

内容検索の結果はファイルごとに1行で、検索数・行・列・一致箇所を一覧表示します。内容検索は到着した結果を順次確認でき、名前検索の結果は検索完了後に一覧表示します。使用した検索エンジン名と版も結果画面に表示されます。

検索結果画面のEは、名前検索では選択したファイルを、内容検索では選択中の一致箇所を設定済みの外部エディタで開きます。外部エディタの引数テンプレートでファイル／行／列を渡せます。このテンプレートは名前検索や通常のBrowserでEを使う場合には適用されません。

結果画面操作 動作
↑ / ↓ 結果を移動します。
← / → 同じファイル内の一致箇所を移動します。
Enter 名前検索の結果は確認用のBrowserで開き、内容検索は内容をプレビューします。
Ctrl + Enter 新しい通常のタブで開き、内容検索の結果はプレビューします。
Ctrl + F 検索完了後、結果があれば検索結果の絞り込み画面を開きます。0件の場合は検索条件を引き継いだ検索画面を開きます。
E 選択中の内容検索結果を設定済みの外部エディタで開きます。引数テンプレートでファイル／行／列を渡せます。
Ctrl + Shift + O / Function BarのOutput 検索が最後まで完了した場合、または一部の結果で終了した場合に、絞り込み前の結果一覧をファイルへ出力し、外部エディタで開きます。完了時は全結果、一部終了時は取得済みの一致箇所と未完了の理由を出力します。
F7 現在の検索条件で再検索します。

補足: ContextMenuのdirectory項目から「新しいtabで開く」を選べます。複数directoryを選択またはMarkしている場合は一括して開き、成功したbatch openはUndo／Redoの1操作です。Workspace Snapshotにshortcutはありません。Fullで既定有効（個別変更可）にすると、tabの右クリックmenuから現在のWorkspace全体を保存できます。

Mark操作とMarkSlot

MidFDでは、複数のファイルをMarkして一括でコピー、移動、削除などの操作を行えます。MarkSlotの保存・復元も通常機能です。集合演算とBackup TransferはFull限定です。

操作 共通キー 説明
Mark切り替え Space / Insert カーソル位置の項目のMark状態を反転させて下に移動します。
ファイルのみ全選択 Home ディレクトリ（フォルダー）を除外し、ファイルのみを全選択/解除します。
フォルダーを含む全選択 End / Ctrl + A すべてのフォルダーとファイルを一括選択/解除します。
MarkSlot画面を開く Ctrl + M 現在のMark状態をスロットに一時保存・復元する画面を開きます。

メディアプレビューと外部連携

内蔵動画Playerと音声の操作

Browserで動画をEnter／Ctrl+Enterすると、内蔵MidPlayer（Media Foundation）で再生します。再生中／一時停止中は固定され、停止・終了・エラーではBrowser選択への追従に戻ります。

操作キー／UI動作
動画を開くEnter / Ctrl + Enter内蔵MidPlayerで再生します。開始時はBrowser選択に追従し、再生中／一時停止中は自動固定します。
固定／追従を切替Viewerの固定button手動で固定を解除すると、動画再生中でも矢印キーをBrowser選択へ送れます。次の実再生状態の変化で自動規則が再評価されます。
固定中の動画操作← / →、↑ / ↓、Space固定中は左右でseek、上下で音量、Spaceで一時停止／再開します。追従中の矢印はBrowser選択を移動します。
対応音声を開くEnter / Ctrl + Enterffplayで外部再生します。ffplayが見つからない場合はWindowsの関連付けを使います。
動画の明示PreviewVfile内容probeによるPreviewです。通常動画はBinary表示で、動画再生は行いません。Windowsの関連付けで開く場合はZを使います。

外部ツール Alt slot launcher

設定で外部ツールにショートカットキー（Alt + 英数字）を割り当てると、ファイラーから一発で起動できます。

操作 キー 説明
ランチャー表示 Alt（単押し） 登録済みの外部ツール一覧スロットを画面に表示します。
スロット直接起動 Alt + 英数字 対応するスロットに登録した外部ツールを直接起動します。
選択して起動 ↑ / ↓ を経て Enter Altで開いたランチャー内で選択を移動し、決定して起動します。

より詳細な割り当てや拡張機能のキー操作については、GitHubのリファレンスドキュメントをご覧ください。
